# ExplainViz 默认启用、空白检测与局部重排

开发基线：`0a88693510b0337467d1b17e4d0bdc11289f2eeb`。用户本轮明确要求默认打开、实现自动空白检测与局部重排，
并在开发完成后由 gpt-6.1-terra / high 子 agent 进行验证，替代此前停止验证的要求。

## 实现范围

- 默认 auto；无请求文件也评估当前页明确关系，使用保守规则生成受约束的三模板决策。
  Agent 提案仍可覆盖规则，并绑定源 IR / 槽位哈希；不隐式调用模型服务。
- 优先复用预留区域。自动空白检测从真实正文边界减去既有对象和安全间距，得到有界空矩形。
  通过既有相对布局树插入图形，并检查原对象位置/尺寸保持在 0.1 CSS px 浮点容差内。
- 空白方案不可表达时，可在当前页正文区尝试上下或左右排布，保持原科学内容、字号和字体，
  保持标题/takeaway 和页面家具。不可读、碰撞、溢出或改变科学内容时回退。
- 默认每页最多 8 次放置尝试，整套上限为图示预算乘以每页次数；记录位置变化和接受的策略。
- allow_local_reflow=false、slot_policy=reserved_only、protected_slide_ids 与 off 提供关闭/保护边界。
- 常规构建及默认四工具的最终候选接入 auto；草稿预览、逐页容量和修补预检显式关闭增强。

不承诺在任意空白处都能插入，也不承诺任意页面都可重排。既有其他视觉对象、来源不明确、
当前相对布局表达不了空白或正文保持门槛失败时仍保守跳过。未添加因果等新图种或自由布局引擎。
